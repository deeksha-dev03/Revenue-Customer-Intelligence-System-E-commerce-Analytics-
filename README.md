**Overview**
This project analyzes e-commerce data to generate insights on revenue, customer behavior, and business performance using SQL, Python, and Power BI.

**Objectives**
Analyze revenue trends
Understand customer behavior
Identify top product categories
Evaluate delivery performance

**Tech Stack**
SQL
Python (Pandas, Matplotlib, Seaborn)
Power BI

**Dataset**
E-commerce dataset (~100k records)
Includes customers, orders, products, and payments
**Note: Original dataset is not uploaded due to size issue.So, cleaned data is uploaded.**

**Workflow**
Data cleaning and transformation (SQL & Python)
Feature engineering (order month, delivery time, customer type)
Exploratory data analysis (EDA)
Dashboard creation in Power BI

**Key Insights**
Most customers are one-time buyers
Few categories contribute majority of revenue
Revenue shows monthly trends
Delivery time varies across orders
